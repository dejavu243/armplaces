# Контрольная серия ArmPlaces

Выполнены 15 000 турниров: N=8, 16, 32, 64, 128; по 1000 независимых повторов
для каждой из трёх моделей, с расчётом GrinTour. Все турниры прошли инварианты
и независимую проверку экспортированных журналов, рейтингов и метрик.

Ревизия расчёта: `166bc93737da403efd375f769deebbbb994db260`; рабочее дерево чистое.
Python 3.12.3; NumPy 2.2.6; NetworkX 3.4.2.
Параметры: seed=42, α=2, β=3, scale=1000, dR=200, K=160, f=0.05.

## Интерпретация и ограничения

- В `strong-win` сильнейший стал чемпионом во всех повторах каждого размера.
- Отбор путей L/L−1 в GrinTour может исключить все связи некоторых участников.
  Участники сохранены в графе, поэтому несколько источников дают явный `undefined`.
  Это объясняет неопределённость даже без случайных побед и циклов.
- В больших категориях успешная выборка GrinTour мала. Её средние нельзя считать
  оценкой качества расстановки для всех турниров или доказательством превосходства над сеткой.
- Это одна воспроизводимая серия с выбранным распределением, не калибровка по реальным
  армрестлинг-турнирам. Статистическая значимость различий моделей здесь не оценивается.
- Случайные потоки двух моделей Эло связаны для сравнения. Независимы повторы,
  а не результаты моделей внутри одного повтора.

## Воспроизведение

Из корня проекта после установки в `.venv`:

```bash
for n in 8 16 32 64 128; do
  .venv/bin/python -m simulation --strong-win --elo --elo-stamina --grin-tour \
    --participants "$n" --repeats 1000 --seed 42 --output "results/n$n" || exit
done
```

Каждый каталог содержит config.json, summary.json, participants.csv, bouts.csv,
tournaments.jsonl, report.md и run.log. Экспорт проверяется автоматически.
Полные журналы исключены из Git; сводные значения здесь перенесены из summary.json.
Для N=16 и N=32 CI выполняет те же команды и сохраняет архивы на 30 дней.

## Проверки и исправления

- 27 тестов и Ruff проходят; зависимости проверены через `pip check`.
- Новая сетка проверена для каждого N=2–128 и всех трёх моделей; проверены
  одиночный участник, оба финала, пропуски, общие места и крайние параметры.
- Исторические таблицы проверены на 50 наборах исходов для каждого N=2–32.
  Оригиналы сохранены; изменения находятся только в `_fix`-копиях.
- Исправлены разбор фамилий и результатов, технические проходы, нулевые и
  конфликтующие переходы, потеря коротких цепочек, усечение обходов, изменение
  входного графа и неявная неполная расстановка.
- Вероятность Эло устойчива для больших рейтингов и малого dR. Проверка артефактов
  обнаруживает не только отсутствующие строки, но и подмену счётчиков/сводных метрик.
- Подробности алгоритмов, отдельных исправлений и структуры `src/` — в [README](../README.md).

## Дополнительный тест: непобедимый участник №1

Команда: `.venv/bin/python -m test.forced_champion`.
Ревизия: `edaadad7890385adec242c5a1c3d902624ceff0c`, seed=42, чистое рабочее дерево.
Для каждого N от 2 до 64 выполнено 1000 случайных жеребьёвок. №1 всегда
побеждает, остальные исходы равновероятны; имена участников — строки 1…N.

| Проверка | Результат |
|---|---:|
| Всего турниров | 63000 |
| №1 — чемпион сетки, без поражений | 63000 |
| Ошибочный чемпион сетки | 0 |
| Нарушения заданного правила исходов | 0 |
| GrinTour выдал полную расстановку, №1 первый | 9408 |
| GrinTour выдал полную расстановку с другим первым | 0 |
| GrinTour не выдал полную расстановку | 53592 |

Причины неопределённости GrinTour: 51 144 цикла после обработки встречных
побед и 2 448 случаев нескольких источников после отбора цепочек.
Циклы возможны среди остальных участников даже при гарантированно непобедимом №1.
Текущая реализация в этих случаях отклоняет полную расстановку и не возвращает
отдельно известного чемпиона. Поэтому успех проверки чемпиона сетки не означает,
что GrinTour смог обработать все 63 000 турниров.

Детализация каждого N сохранена локально в `results/forced-champion/by_size.csv`,
метаданные — в `summary.json`, воспроизводимые примеры неопределённости —
в `undefined_examples.json` того же каталога. Полный тест запускается явно,
вне обычного `unittest discover`.
