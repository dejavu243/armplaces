# GrinTour: фиксация мест по решающим боям

Реализованы правила: финал без суперфинала или суперфинал определяют места 1–2;
проигравший решающего полуфинала нижней сетки получает место 3. Затем продолжается
расчёт остальных мест. Призёры не теряются при неразрешимой нижней части графа.

## Воспроизводимость

Ревизия расчётов: `4be528914f5625d8fa4bfb10f370a6860f8069e8`; рабочее дерево чистое.
Python 3.12.3; seed=42. Исходные таблицы DE_OLD не менялись.

```bash
.venv/bin/python -m test.forced_champion --output results/forced-champion-final-places
for n in 16 32; do
  .venv/bin/python -m simulation --strong-win --elo --elo-stamina --grin-tour \
    --participants "$n" --repeats 1000 --seed 42 --output "results/final-places-n$n" || exit
done
```

## Непобедимый №1: 63 000 турниров

Для каждого N=2…64 выполнено 1000 турниров. №1 побеждает всегда, остальные бои
равновероятны. Проверяются не только чемпион, но и вся доступная тройка.

После изменения 42 582 частичных результата связаны с циклами среди остальных
участников, 5 203 — с несколькими источниками после отбора длинных цепочек.
Эти ограничения нижних мест не мешают сохранить доказанные призовые места.

По 1000 повторов на модель для каждого размера. В обеих версиях одинаковые
участники, жеребьёвка и исходы: изменяется только GrinTour.

| N | Модель | Полных раньше | Полных теперь | Только призёры | Без известных мест |

Всего проверено ещё 6000 турниров трёх моделей. Все артефакты прошли

с исходами решающих боёв и местами по сетке. MAE/Spearman по-прежнему рассчитываются
только для полных расстановок, без подмешивания частичных троек.

## Что изменилось в графе

Исходный журнал не изменяется. После обработки повторных встреч из проекции
удаляются связи, противоречащие доказанным призовым местам. Добавляются ограничения
порядка 1 выше 2 выше 3, каждый непризёр ниже третьего. Это отношения итоговых мест,
не дополнительные поединки. Циклы исключительно среди остальных участников
не разрываются произвольно. При неудаче возвращается только доказанная тройка.

## Проверки

Регрессионные тесты охватывают финал без суперфинала, оба исхода суперфинала,
полуфинал, N=1/2, неполные журналы, технические проходы, дополнительные встречи
за 5–6 до и после финала, сохранение призёров при цикле и разорванном графе,
CSV/JSON для `partial` и сохранение историческим CLI. Все 36 тестов и Ruff проходят.

Артефакты теперь имеют схему 2. Для проверки старых артефактов используйте код
ревизии, записанной в их config.json. Полные правила — в [README](../README.md).
