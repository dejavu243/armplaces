# Контрольная серия на DE_OLD_fix

Ревизия расчёта: `776f9c4fd16fc489e897073f4b46dccf4982053b`; рабочее дерево чистое.
Python 3.12.3, NumPy 2.2.6, NetworkX 3.4.2. Установки и запуски — через `.venv`.

## Что проверено

Симуляция читает переходы из `DE_OLD_Winner_fix` и `DE_OLD_Loser_fix`.
GS содержит 4N ячеек; жеребьёвка занимает первые N. Бой i читает ячейки
2i−1 и 2i. Индексы Python: строка i−1, столбец N−2, адрес назначения d−1.
Адреса проигравших за пределами GS сохранены в `eliminated_slots`:
это выбывшие после второго поражения, а не следующие бои.
Для N>32 выводится ошибка отсутствия таблицы. N=1 — победитель без боёв.

Это другая сетка по сравнению с предыдущей серией. Старые результаты и
команды сохранены в [архиве](experiment-report-before-de-old-fix.md).
Пошаговый пример с полной GS после каждого боя: [пайплайн N=9](gs-pipeline-example.md).

## Параметры и полнота

N=8, 16, 32; по 1000 повторов каждой из трёх моделей — **9000 турниров**.
seed=42, α=2, β=3, scale=1000, dR=200, K=160, f=0.05.

| N | Расставлены графом | По рейтингам: цикл | По рейтингам: потеря связей | Турниров с определёнными местами всех участников |
|---:|---:|---:|---:|---:|
| 8 | 3000 | 0 | 0 | 3000 |
| 16 | 2406 | 19 | 575 | 3000 |
| 32 | 1416 | 40 | 1544 | 3000 |

Во всех 9000 турнирах места определены полностью; `partial=0`, `undefined=0`.
Призёры совпадают с решающими боями. Рейтинговое сравнение использует исходные
рейтинги соперников: это метод с доступом к ним, а не оценка только по боям.

## Проверки

- 44 теста unittest и Ruff прошли.
- Для всех N=2…32 адреса симуляции совпадают с исходными столбцами `_fix`.
- Независимый проход по таблицам проверен на 30 случайных исходах для каждого N.
- Экспорт каждого турнира проверен повторным проходом по GS и таблицам.
- Проверены суперфинал, финал без переигровки, N=1, отказ для N>32 и повреждение GS.
- Тест непобедимого № 1: **31 000 турниров**, N=2…32, по 1000 на размер.
  Во всех случаях № 1 — чемпион; места GrinTour полные; ошибок исходов и призёров нет.

## Воспроизведение

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m unittest discover
.venv/bin/python -m ruff check .
for n in 8 16 32; do
  .venv/bin/python -m simulation --strong-win --elo --elo-stamina --grin-tour \
    --participants "$n" --repeats 1000 --seed 42 --output "results/de-old-fix/n$n" || exit
done
.venv/bin/python -m test.forced_champion --repeats 1000 --seed 42 \
  --output results/de-old-fix/forced-champion
.venv/bin/python -m simulation.trace --participants 9 --seed 42 --model strong-win
```

Артефакты в `results/de-old-fix/` не коммитятся. Формат — schema_version=3.
Каждая категория содержит конфигурацию и версии, CSV участников и боёв,
JSONL с GS и адресами выбывших, JSON-сводку, Markdown-отчёт и лог.
Это результаты локальных запусков. Удалённый CI в рамках этой проверки не запускался.
