# Эксперимент: последовательная жеребьёвка и рейтинговое разрешение GrinTour

Ревизия расчёта: `214a78d8676419b98179a8a9b6eff93e64022ed4`, чистое рабочее дерево.
Python 3.12.3, NumPy 2.2.6, NetworkX 3.4.2. Все команды выполнены через `.venv`.

N=8, 16, 32, 64, 128; по 1000 повторов каждой из трёх моделей: 15 000 турниров.
seed=42, α=2, β=3, scale=1000, dR=200, K=160, f=0.05.

## Изменения

Участники жеребьёвки записываются последовательно в ячейки 1…N; пары соседние.
Для N=9 первый тур содержит четыре реальных боя и один технический проход.
При отказе графа GrinTour сохраняет призёров и сравнивает всех остальных по
минимальному исходному рейтингу победившего их соперника (больше — выше), затем
по максимальному исходному рейтингу побеждённого (больше — выше), затем по
порядку жеребьёвки. Используется исходный журнал, включая встречные бои;
технические проходы исключаются. Без побед второй показатель равен нулю.

Это метод с доступом к исходным рейтингам, а не оценка исключительно по боям.
Вместе с изменением GrinTour исправлены пары жеребьёвки: сравнение со старой
серией не является сравнением методов на одинаковых боях.
Предыдущий отчёт: [архив](experiment-report-before-opponent-ratings.md).

## Воспроизведение

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m unittest discover
.venv/bin/python -m ruff check .
for n in 8 16 32 64 128; do
  .venv/bin/python -m simulation --strong-win --elo --elo-stamina --grin-tour \
    --participants "$n" --repeats 1000 --seed 42 --output "results/consecutive-ratings/n$n"
done
.venv/bin/python -m test.forced_champion --repeats 1000 --seed 42 \
  --output results/consecutive-ratings/forced-champion
```

Результаты остаются в `results/consecutive-ratings/` и не коммитятся. Каждый
каталог N содержит конфигурацию, версии, CSV участников и боёв, JSONL турниров,
JSON-сводку, Markdown-отчёт и лог. В JSONL поле `method=opponent_ratings`
отмечает применение сравнения; `graph_reason` сохраняет причину отказа графа.
CI использует те же обновлённые функции для N=16 и N=32; приведённые здесь
результаты получены локально, запуск удалённого CI в эту проверку не входит.
