# Контрольная серия ArmPlaces с новым GrinTour

Повторены все 15 000 турниров исходного эксперимента: N=8, 16, 32, 64, 128;
по 1000 независимых повторов на каждую из трёх моделей. Новый GrinTour сначала
фиксирует места 1–3 по финалу/суперфиналу/полуфиналу, затем определяет остальные.
Если нижнюю часть определить невозможно, призёры сохраняются со статусом `partial`.

Ревизия расчёта: `cec4813fe09bbc875423a7999e217b7cd275abd1`; рабочее дерево чистое.
Python 3.12.3; NumPy 2.2.6; NetworkX 3.4.2.
Параметры сохранены: seed=42, α=2, β=3, scale=1000, dR=200, K=160, f=0.05.

Все турниры прошли инварианты и независимую проверку экспортированных журналов,
рейтингов, призовых мест и метрик. Для каждого из пяти размеров SHA-256 файлов
`bouts.csv` совпал со старым экспериментом: составы боёв, исходы, вероятности и нагрузка
побайтно одинаковы. Метрики сетки и частота победы сильнейшего также совпадают.

## Интерпретация и ограничения

- Во всех моделях известные призёры теперь сохраняются независимо от нижней части графа.
- В `strong-win` сильнейший стал чемпионом во всех повторах каждого размера.
- Ограничения призовых мест разрывают противоречащие им циклы, но циклы только среди
  остальных участников не разрешаются произвольно. Отбор цепочек L/L−1 также может
  оставить некоторые вершины без связей; в обоих случаях возвращается `partial`.
- MAE/Spearman GrinTour относятся только к выборке `ok`. Её состав отличается от старой
  версии и от полной выборки сетки. Прямое сравнение этих средних не доказывает
  превосходство одного метода. Для больших категорий полная выборка особенно мала.
- Это одна серия на выбранных параметрах, без проверки статистической значимости
  различий и без калибровки по реальным соревнованиям. Независимы повторы; две модели
  Эло используют связанные случайные потоки внутри повтора.

## Воспроизведение

Из корня проекта после установки в `.venv`:

```bash
for n in 8 16 32 64 128; do
  .venv/bin/python -m simulation --strong-win --elo --elo-stamina --grin-tour \
    --participants "$n" --repeats 1000 --seed 42 --output "results/new-grintour/n$n" || exit
done
```

Каждый каталог содержит `config.json`, `summary.json`, `participants.csv`, `bouts.csv`,
`tournaments.jsonl`, `report.md` и `run.log`. Экспорт проверяется автоматически.
Сопоставление со старой серией и SHA-256 журналов сохранены в
`results/new-grintour/comparison.json`. Сырые результаты исключены из Git.
Новые артефакты имеют схему 2; старые проверяются кодом их записанной ревизии.

## Дополнительная проверка непобедимого №1

Отдельный ранее выполненный повтор на этой же ревизии: N=2…64, по 1000 турниров,
всего 63 000, seed=42. Он не включён в 15 000 турниров основной серии выше.
№1 стал чемпионом сетки и GrinTour во всех случаях; ошибок призовой тройки — 0.
Полная расстановка: 15 215; только призёры: 47 785; без известных мест: 0.
Результаты сохранены в `results/forced-champion-repeat/`.
