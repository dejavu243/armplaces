# Контрольная серия: GrinTour сохраняет все ветви

Расчётный код: `4372583`. N=8, 16, 32; три модели; по 1000 повторов, seed=42.
Всего 9000 турниров. Параметры: α=2, β=3, scale=1000, dR=200, K=160, f=0.05.
Python 3.12.3, NumPy 2.2.6, NetworkX 3.4.2; запуск через `.venv`.

## Изменение

Удалён отбор только цепочек длины L и L−1. Сохраняются все ветви ациклического
графа после фиксации призовой тройки. Вес ребра — число всех полных путей через него.
Короткие и соединяющиеся ветви не удаляются; вершины не дублируются.
Циклы по-прежнему разрешаются сравнением исходных рейтингов соперников.

## Пример с восстановленными ветвями

В примере N=16, repeat=24, strong-win участники № 16, № 9 и № 8 больше не
изолированы. Без рейтингов они получают места 7, 8 и 10 соответственно.
[Разбор и новый граф](grintour-examples/04-isolated-group.md).

## Воспроизведение

```bash
.venv/bin/python -m unittest discover
.venv/bin/python -m ruff check .
for n in 8 16 32; do
  .venv/bin/python -m simulation --strong-win --elo --elo-stamina --grin-tour \
    --participants "$n" --repeats 1000 --seed 42 --output "results/all-branches/n$n" || exit
done
.venv/bin/python -m test.forced_champion --repeats 1000 --seed 42 \
  --output results/all-branches/forced-champion
```

Артефакты находятся в `results/all-branches/`, формат schema_version=3.
В манифестах `dirty=true`: присутствовали пользовательские файлы изображений
и обновлялась документация. Расчётные модули во время серии не менялись.
Это локальные результаты; удалённый CI в рамках этой проверки не запускался.
