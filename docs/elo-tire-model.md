# Математическая модель elo-tire

Модель используется для проверки точности расстановки мест: исходный рейтинг
идеально отражает силу спортсмена, жеребьёвка случайная, исходы боёв вероятностные.
Рейтинги не пересчитываются между боями; накопленная усталость изменяет эффективную
силу. Посев по рейтингу в этой реализации отсутствует.

## Источники и изменения формул

Гринёв И.В., Парамонов И.Н., Соловьёв М.В., Мастин А.Ю.
«Система проведения соревнований по армрестлингу с посевом (расстановкой по рейтингу)».
Ученые записки университета имени П.Ф. Лесгафта, 2021, №4(194), с.122–125.
[DOI: 10.34835/issn.2308-1961.2021.4.p122-125](https://doi.org/10.34835/issn.2308-1961.2021.4.p122-125).

Модель рейтингов в статье:

```text
F(R) = 1 − exp(−((R−R_min)/λ)^k), R ≥ R_min
k = 2.2; λ = 220; R_min = 852
```

В статье эффективный рейтинг записан как:

```text
R(S) = R₀ · [A + (1−A) · ((A′−A)/(1−A))^(S/(N_f·C))]
S_a ← S_a + |C − (R_a − R_b)|
S_b ← S_b + |C − (R_a − R_b)|
S_a,0 = S_b,0 = 0
A = 0.90; A′ = 0.85; C = 400; N_f = 3
```

Здесь основание степени равно −0.5. При произвольной дробной степени действительное
значение не определено. В реализации **параметры переставлены**: A=0.85, A′=0.90.
Это явно выбранное исправление модели, а не подтверждение опечатки в публикации.
Параметры усталости в статье основаны на экспертной оценке; физиологическая
калибровка текущей реализации не проведена.

Вероятность победы в статье задаётся в процентах:

```text
P_percent(ΔR) = 100 / [1 + ((1−p)/p)^(ΔR/ΔR_m)]
p = 0.99; ΔR_m = 100
```

Это эквивалентно формуле Эло с dR=100/log₁₀(99)≈50.1094.
В проекте elo-tire использует общую формулу с dR=200 по умолчанию:

```text
P(a победит) = 1 / [1 + 10^((R_eff,b − R_eff,a)/dR)]
```

При равной силе P=0.5; преимущество 100 пунктов даёт P≈0.759747,
200 пунктов — P=10/11. `--dr` настраивается и применяется ко всем моделям Эло.

[Гринёв, Усманов, Парамонов, «Подбор параметров рейтинга Эло в армрестлинге», 2023](https://uchzapiski.lesgaft.spb.ru/temp/b5ca5c04f96688a320c54d029f91b1e8.pdf)
связывает диапазон значений рейтинга с абсолютными коэффициентами рейтинговой
системы. Фиксированные универсальные минимальный и максимальный рейтинги из
этой работы не следуют; границы в CLI являются параметрами эксперимента.

## Проведение боя

1. Для каждого участника хранить исходный рейтинг R₀ и накопленную усталость S.
2. Перед боем получить R_eff по формуле выше; победителя выбрать сравнением
   равномерного U∈[0,1) с вероятностью Эло.
3. По значениям **перед боем** вычислить L=|C−(R_eff,a−R_eff,b)|.
4. Одновременно увеличить S обоих участников на L, независимо от победителя.

`a`, `b` соответствуют порядку ячеек генеральной последовательности. Формула
нагрузки зависит от этого порядка: при C=400 и рейтингах 1000/1100 нагрузка
равна 500, при перестановке — 300. Эта особенность записи статьи сохранена.
Большая разница рейтингов также может увеличивать нагрузку; симметричная
альтернативная модель в данном варианте не реализована.

Восстановления нет. Технический проход не расходует случайное число и не
увеличивает усталость. При N=1 единственный участник получает первое место без боёв.
Выбывание — после двух поражений; финал и суперфинал используют существующую сетку.

## Параметры усталости

| CLI | По умолчанию | Значение |
|---|---:|---|
| `--tire-floor` | 0.85 | A, нижний предел доли силы |
| `--tire-reference` | 0.90 | A′, доля силы при S=N_f·C |
| `--tire-c` | 400 | C, масштаб нагрузки в пунктах рейтинга |
| `--tire-bouts` | 3 | N_f, число равных боёв до опорной доли силы |

Требуется 0<A<A′≤1, C>0, положительное целое N_f; все вещественные значения конечны.
При S=0 сила равна R₀; при S=1200 она равна 0.90·R₀; при S→∞ стремится к 0.85·R₀.
При A′=1 сила фиксирована и исходы совпадают с elo при одинаковом seed.
Коэффициенты доступны для дальнейших исследований; текущая серия оценивает
выбранный набор, без подбора по критерию совпадения с эталонными местами.

## Генерация рейтингов и диапазоны

| Распределение | Формула и параметры по умолчанию |
|---|---|
| `beta-prime` | R=530·G₁/G₂; G₁~Gamma(135.1,1), G₂~Gamma(65.2,1), усечение `[600,1900)` |
| `weibull` | R=852+220·W; W~Weibull(2.2) |
| `uniform` | R~Uniform[600,1900) |

Форма и масштаб бета-прайм задаются прежними `--alpha`, `--beta`, `--scale`.
Новые значения получены [подбором по 187 реальным рейтингам](beta-prime-calibration.md).
Прежние 2, 3, 1000 давали слишком широкий неограниченный хвост для этих данных;
формула отношения гамма-величин была корректна. Диапазон 600–1900 выбран пользователем.
Для Вейбулла используются `--weibull-shape`, `--weibull-scale`, `--weibull-location`.
Сдвиг Вейбулла конечный и неотрицательный, форма и масштаб положительны.

`--rating-min L --rating-max U` задаются парой, 0<L<U, оба значения конечны.
Для uniform это прямые границы. Для остальных используются значения исходного
распределения, попавшие в [L,U): распределение условное, без обрезания значений,
растяжения выборки или требования достигнуть её границ.
Без явных границ beta-prime использует `[600,1900)`, Вейбулл сохраняет неограниченный хвост.
`--unbounded-beta-prime` отключает границы beta-prime; вместе с `--alpha 2 --beta 3 --scale 1000`
он позволяет воспроизвести историческую модель. Этот флаг несовместим с явным диапазоном.
Интервал Вейбулла должен пересекать область R>location.
Бюджет — 100000 кандидатов на повтор; слишком маловероятный интервал вызывает ошибку.
Сгенерированные рейтинги конечны и положительны.

Uniform [600,1900) — выбранный исследовательский диапазон, а не оценка
реальных границ из статьи. Различия результатов распределений отражают и форму,
и выбранные масштабы рейтингов.

## Оценка мест

Эталон — исходные рейтинги по убыванию, равенства разрешаются по ID.
Основной алгоритм `grin-cycle` не использует исходных рейтингов. `grin-elo`
сравнивается отдельно, поскольку его резерв использует рейтинги соперников.

Для каждого истинного места r и полного турнира δ=полученное место−r.
Пять столбцов: r, Var(δ) с ddof=0, mean(|δ|), max(0,max δ), max(0,−min δ).
Положительное δ означает ухудшение, отрицательное — улучшение места.
Неполные расстановки исключаются целиком, число исключённых повторов показывается.
Во всех моделях одного повтора исходные рейтинги и жеребьёвка одинаковы;
Эло-модели используют отдельные генераторы с общим потоком случайных чисел.
