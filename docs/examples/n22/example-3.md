# Пример 3: 22 участника

Три независимых турнира Elo-tire: N=22, seed=42, повторы 0, 1, 2. Рейтинги beta-prime: α=135.1, β=65.2, scale=530, диапазон [600,1900). A=0.85, A′=0.9, C=400, N_f=3, dR=200. Каждый пример имеет собственные рейтинги, жеребьёвку и исходы. Четыре метода распределяют места по одному и тому же журналу боёв.

Спортсмены обозначены номерами 1–22 во всех таблицах и CSV этого отчёта; в исходных артефактах ID начинаются с 0. Истинное место — порядок исходных рейтингов по убыванию, равенства по ID. Для исхода боя используются эффективные рейтинги с усталостью, без округления; показанные числа округлены. P(A) — вероятность победы первого в паре. W — верхняя сетка, L — нижняя. Технический проход не считается боем.

Zhivora-Tour: фиксированы места 1–6, групповой проход начинается с 7-го. Для N=22 сохранена проверка обычной ветви: два претендента на 5–6 должны проиграть разным участникам из первой четвёрки, один — будущему четвёртому. Во всех трёх примерах условие выполнено; вес спортсменов не используется.

Повтор 2; реальных боёв: 42; технических проходов: 0. Суперфинал: нет. Чемпион — №2, его истинное место: 1.
