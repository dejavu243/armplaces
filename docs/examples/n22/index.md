# Примеры турниров для 22 участников

Независимых турниров Elo-tire: 3; N=22, seed=42, повторы 0, 1, 2. Рейтинги beta-prime: α=135.1, β=65.2, scale=530, диапазон [600,1900). R_eff=R₀·0.85^(S/1002). A′=0.85, C=334, N_f=3, dR=167. Каждый пример имеет собственные рейтинги, жеребьёвку и исходы. Четыре метода распределяют места по одному и тому же журналу боёв.

Спортсмены обозначены номерами 1–22 во всех таблицах и CSV этого отчёта; в исходных артефактах ID начинаются с 0. Истинное место — порядок исходных рейтингов по убыванию, равенства по ID. Для исхода боя используются эффективные рейтинги с усталостью, без округления; показанные числа округлены. P(A) — вероятность победы первого в паре. W — верхняя сетка, L — нижняя. Технический проход не считается боем.

При |R_eff,A−R_eff,B| < 334 к S обоих спортсменов добавляется ΔS=334−|R_eff,A−R_eff,B|. При разнице от 334 включительно S обоих остаётся прежним. ΔS — добавка за один бой; S — сумма добавок за предыдущие бои. Ни S, ни ΔS не делятся на 1002. Деление S на N_f·C=3·334=1002 применяется только в показателе степени R_eff. В CSV сохранена полная точность; в таблицах показано шесть знаков после запятой.

Zhivora-Tour: фиксированы места 1–6, групповой проход начинается с 7-го. Для N=22 сохранена проверка обычной ветви: два претендента на 5–6 должны проиграть разным участникам из первой четвёрки, один — будущему четвёртому. Во всех примерах условие выполнено; вес спортсменов не используется.
